# My GitHub 101 Takeaway

Going into this article, GitHub felt like a tool just for coders — something I'd hear engineers reference but never actually touch myself.

What changed my mind was the Google Drive framing. Once branches became "suggestion mode," commits became "save points," and pull requests became "review cycles," GitHub stopped feeling like a coding tool and started feeling like what it really is — a version control and collaboration tool.

Walking through the full flow step by step — pull, branch, commit, push, PR, merge — also made the workflow click. As a product manager, I can see this being genuinely useful well beyond code: PRDs, playbooks, decision logs, anything that evolves over time and needs review.
